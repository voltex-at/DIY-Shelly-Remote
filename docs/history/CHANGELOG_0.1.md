# Changelog

## 0.1.0-bringup - 2026-10-15

- Added the documented LCDWiki ES3C35P N16R8 profile and dual-slot 16 MiB Flash layout.
- Added ST77922 QSPI and integrated-touch bring-up with attributed initialization data.
- Added the LVGL hardware-test UI, colors/corners, brightness and first-touch wake.
- Added board-specific CI hardware-test artifacts and USB/test instructions.
- Published/merged the foundation after native ASan/UBSan and ESP32/S3 diagnostic CI passed.
- Physical validation, Wi-Fi/device UI, BLE and OTA installation remain pending.

## 0.0.1-dev - 2026-10-15

- Created the independent project foundation and hardware confirmation gate.
- Added portable request builders, bounded device registry and OTA metadata/version policy.
- Added ESP-IDF HTTP, NVS, Wi-Fi and queued worker source, pending target compilation.
- Added native tests, diagnostic CI and initial project documentation.
- No supported board, firmware binary, hardware test or public release yet.
